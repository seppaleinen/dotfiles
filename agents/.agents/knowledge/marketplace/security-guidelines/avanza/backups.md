# Backups and recovery

Data backups must exist, be encrypted, and be periodically tested for recoverability. Know what data you can afford to lose and how long recovery can take. Store backup data in a separate location from ordinary storage (different region, location, or datacenter).

Source: Avanza Technical Security Requirements.

Load this when designing persistence, changing backup jobs, or reviewing DR. Pair with [incident readiness](/avanza/incident-readiness.md).
