# General output sections

Not a selectable format — shared layout for **every** final review artifact. Use together with the chosen output format file (`default.md`, `table.md`, …).

Findings sections use the chosen format file. Insert between `### Verdict` and `### Transparency` below.

## Section contract

Apply to every output format (format files are layout only).

**Required sections:**

- `### Change brief` — always before `### Verdict`; subsections per [`checkpoints/change-brief.md`](../checkpoints/change-brief.md); refine the locked change brief if findings add nuance
- `### Verdict` — always; one sentence per [Verdict](#verdict) below
- `### Requires Human Review` — when human sign-off gates fired
- At least one of `### Blocking`, `### Suggestions`, `### Nits` — when findings exist
- `### Transparency` — always; footer per [Transparency footer](#transparency-footer) below

## Findings behaviour (all formats)

- **`### Requires Human Review`** — when human sign-off gates fired; omit otherwise
- **Empty sections** — omit, do not print empty headers
- **`### Suggestions`** — craft and design findings, not only soft bugs; include alternatives ("this works; consider …")
- **`### Praise`** — notably good craft or design choices
- **Citation tags** — per [`finding-citations.md`](finding-citations.md)

## Verdict

One sentence: **recommend merge**, **recommend changes**, or **insufficient context**. Never "approve", "approved", or "request changes" as merge authority.

## Transparency footer

End `### Transparency` with: *This is not a merge approval.*
